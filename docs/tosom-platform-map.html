Autentisering

📝 Register

/register

Vipps OAuth registrering. Raskt (2 sek.), ingen passord. Sender til Onboarding etter signup.

Auth Vipps OAuth

🔑 Login

/login

Vipps OAuth innlogging. Sjekk om profil er ferdig → Dashboard eller Onboarding.

Auth Vipps OAuth

Kjerneflyt (Core)

🧭 Onboarding

/onboarding

Dyp profilbygging i 13 steg: Identitet → Livssituasjon → Personlighet → Tilknytning → Kjærlighetsspråk → Livsstil/Verdier → Relasjonsstil → Framtid → Humor → Grenser → Modenhet → Oppsummering → Start reisen. Alt privat, ingen andre ser profilen.

Core 13 steg ~75 felt Privat

📊 Dashboard

/dashboard

Hovedoversikt etter innlogging. Viser match-status, journey-fremskritt, venteliste-informasjon, rask tilgang til Chat, Matching, Reise, Profil og Innstillinger.

Core Oversikt Match-status Navigasjon

Hovedfunksjoner

🎯 Matching

/matching

Viser match-score, scoring-breakdown (9 dimensjoner), resonans-nivå. Bruker kan akseptere eller avslå match. Én match per 24 timer. Ingen bilder, ingen overflate.

Feature Score Breakdown Resonans Én/24t

💬 Chat-oversikt

/chat

Liste over aktive samtaler. Mood-farge-indikator per konversasjon. Unread-count. Klikk for å åpne samtale.

Feature Mood-farger Konversasjoner

💬 Samtale (Conversation)

/chat/[id]

Privat chat mellom to personer. Fri chat med mood-badge. Bli-kjent-spørsmål som tips når samtale stille >10 min. Bilder tillatt fra dag 15. Ingen AI-svar.

Feature Fri chat Mood-badge Bli-kjent tips Bilder fra D15

🧳 Reise / Journey

/reisen

30-dagers guidet reise. Daglig tema + refleksjonsprompt (frivillig). 3 faser: Early (1-14), Building Trust (15-21), Deeper (22-30). Milepæler på dag 3/7/10/14/21/28/30. Bilder tillatt fra dag 15.

Feature 30 dager 3 faser Milepæler Frivillig

👤 Profil

/profile /profile/edit

Se og rediger egen dyp profil. Alle 13 onboarding-felt tilgjengelige for oppdatering.

Feature Vis Rediger

# ToSom – Språkprofil

**Gjeldande frå:** 2026-06-22  
**Base:** Norsk bokmål

---

## Reglar

1. **Brødtekst skal vere bokmål**  
   - "ikkje" → "ikke"  
   - "meir" → "mer"  
   - "vaksne" → "voksne"  
   - "kven" → "hvem" (med mindre bevisst val)  
   - "ein" → "en" (med mindre bevisst val)  
   - "tilbake" → "tilbake" (bokmål)  
   - "sammen" → "sammen" (bokmål)  
   - "gjennom" → "gjennom" (bokmål)  
   - "eller" → "eller" (bokmål)  

2. **Tillatt nynorsk i:**  
   - Tagline: `"Ein rolig, privat plattform for ekte relasjonar."` (bevisst val)  
   - Enkelte overskrifter der det føles naturlig og stemmer med tonen  
   - UI-meldingar og knappar der det gir en god flyt  

3. **Konsekvens over perfeksjon**  
   - Det viktigaste er at tekster kjennes konsistente  
   - Ikke endre bevisst nynorsk til bokmål berre for konsistens  
   - Men fjern feil/motsettning der det sprikjer (f.eks. "meir" i staden for "mer" i brødtekst)  

4. **Tone of voice:**  
   - Roelig, varm, trygg  
   - Aldri pushy eller gamified  
   - Aldri "dating-app-språk"
